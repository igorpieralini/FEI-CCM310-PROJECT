# Exchange de Criptomoedas

## Sobre o projeto

Projeto individual desenvolvido para a disciplina de Arquitetura de Software e Programação Orientada a Objetos (CCM310) do Centro Universitário FEI.

O objetivo é desenvolver uma exchange de criptomoedas em Java, permitindo que um investidor realize operações com Bitcoin, Ethereum e Ripple.

## Funcionalidades

- Login com CPF e senha.
- Consulta de saldo e extrato.
- Depósito e saque em reais.
- Compra e venda de criptomoedas.
- Aplicação de taxas nas operações.
- Atualização das cotações das criptomoedas.

## Tecnologias utilizadas

- Java
- PostgreSQL
- JDBC
- Maven
- NetBeans
- MVC
- Programação Orientada a Objetos

## Estrutura do projeto

O projeto está organizado em classes responsáveis pelos dados, regras de negócio, controle das operações e comunicação com o banco de dados.

Foram utilizados conceitos de POO e princípios SOLID para manter o código organizado e facilitar futuras alterações.

## Como executar

1. Abrir o projeto no NetBeans.
2. Configurar o PostgreSQL.
3. Executar o script SQL do projeto.
4. Ajustar os dados de conexão com o banco.
5. Compilar o projeto utilizando Maven.

## Situação atual

A lógica principal do sistema está implementada. Ainda faltam as interfaces gráficas em Java Swing, que serão desenvolvidas pelo GUI Builder do NetBeans, além dos testes completos de integração.
